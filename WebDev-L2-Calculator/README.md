## Objective
A fully functional browser-based calculator supporting basic arithmetic operations
with a button-grid interface.

## Tech Stack
- HTML5
- CSS3 (CSS Grid for button layout)
- JavaScript (Vanilla)

## Features
- [x] Display screen showing current input and result
- [x] Numeric buttons (0–9) and decimal point
- [x] Operator buttons: +, −, ×, ÷
- [x] Equals (=) button
- [x] Clear (C) button
- [x] Backspace/Delete button
- [x] Division-by-zero handling (no crash, clear error message)
- [x] Operator chaining (e.g. 5 + 3 × 2 without a full reset)
- [x] CSS Grid used for button layout
- [x] Event listeners only — no inline `onclick` attributes
- [x] Bonus: percent key, keyboard input support (digits, operators, Enter, Backspace, Esc)

## How to Run
Open `index.html` in any modern browser. No build step or dependencies required.
